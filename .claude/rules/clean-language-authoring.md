# Author repository and website prose in Clean Language

All prose written for this repository and for the cleanlanguage.ai website must
follow the Clean Language standard. This includes website copy, README and
documentation text, `INSTALL.md`, `NOTICE.md`, release notes, and commit and
pull request descriptions.

The authority for the standard is the skill in this repository:

- [`cleanlanguage/SKILL.md`](../../cleanlanguage/SKILL.md)
- [`cleanlanguage/references/`](../../cleanlanguage/references/)

Apply that skill directly. Do not restate its rules here, so that this
instruction follows the skill whenever the skill changes. When the skill and any
older convention disagree, the skill governs.

The website is a public example of the standard it promotes, so its copy is held
to the same rules as any other Clean Language output. Preserve factual,
technical, legal, and semantic meaning first, then improve clarity, directness,
density, and cadence. Do not introduce a defect, an owner, evidence, or a
conclusion that the source text did not contain.

The repository writing conventions remain in force as part of this standard:
Oxford English with -ize endings, and no em dashes or en dashes.
