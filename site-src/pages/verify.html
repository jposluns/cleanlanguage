What a checksum is

What a checksum is

A SHA-256 checksum is a short fingerprint of a file. The same file always produces the same fingerprint, and changing even 1 byte produces a different one. Each Clean Language release publishes the checksum of its zip file. If the checksum you calculate for your copy matches the published value, your download matches the published release and reached you intact.

How

How to verify

Step 1

Download the skill. The published checksum is shown under the link.

{{release.zip_name}} (opens in a new tab)

zip, version {{release.version}}, SHA-256

The published checksum for version {{release.version}} is:

{{release.checksum}}

The same value is in the published checksum file (opens in a new tab), if you would rather compare files than read.

Step 2

Calculate the checksum of the file you downloaded. First open a terminal in your Downloads folder:

  • On Windows: open your Downloads folder in File Explorer, click the address bar, type powershell, and press Enter.
  • On macOS: press Command+Space, type Terminal, press Return, then type cd Downloads and press Return.

Copy the command for your system, paste it into the window, and press Enter.

Windows (PowerShell)

Get-FileHash {{release.zip_name}} -Algorithm SHA256

macOS

shasum -a 256 {{release.zip_name}}

Linux

sha256sum {{release.zip_name}}

Step 3

Compare the value your computer prints with the published checksum shown in step 1. Letter case does not matter: PowerShell prints the hash in upper case, while the published value is lower case, so compare the letters and digits and ignore the case. A match means your copy matches the published release.

If the two differ, delete the file, download it again, and check once more. If the values still differ after a fresh download, do not install the file and report it on GitHub (opens in a new tab).
