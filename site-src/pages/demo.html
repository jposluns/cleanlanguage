Prompt

Try it on your own writing

Copy the prompt and paste it into ChatGPT, Claude, Gemini, Copilot, or any other assistant that can browse the web. Add your own text where the prompt says to. The prompt has the assistant read the standard straight from this project, so it applies the real rules rather than a summary.

Read first

Read any prompt before you paste it. The prompt below asks the assistant to read the Clean Language standard from this project’s public GitHub repository and rewrite the text you provide. It points only at this project’s own public files.

If your AI cannot browse the web: copy everything from the instructions page, paste it into the chat, and say: Follow these writing rules, then rewrite the text below.

The prompt

First, read the Clean Language standard from its public GitHub repository at https://github.com/jposluns/cleanlanguage. The full standard is in cleanlanguage/skills/cleanlanguage/SKILL.md and the files under cleanlanguage/skills/cleanlanguage/references/. The same rules in a single file are at https://raw.githubusercontent.com/jposluns/cleanlanguage/main/site/downloads/cleanlanguage.md, which may be easier to load. If you cannot reach either, say so rather than guessing. Then apply the standard to the text below. Preserve every fact, figure, quotation, defined term, and technical detail, and do not change the meaning. [paste your text here]

Without JavaScript the Copy button stays hidden: select the prompt text and copy it, then paste it into your AI.

Afterwards

Make it your default

Once you install the skill, you can tell your assistant to always use Clean Language in your personal, project, or chat instructions, or ask for it on demand. Installing is also the way to use Clean Language when your assistant cannot reach the web.
