Install

Claude website or Claude Desktop

Last verified 27 August 2026.

This is the recommended Claude method. It installs the complete Skill, so the full standard is available in any chat rather than pasted into one. Claude applies it when you ask for it, and you can set it to apply by default: see How to use Clean Language on the install page.

Install from a desktop browser. The mobile apps are not documented to support skill upload. Use the skill (zip) from Get Clean Language.

  1. Click your name in the bottom-left corner, then Settings.
  2. Open your skills: on a personal account, click Customize; on a Team account, the Skills area sits under the Customize section.
  3. Click Add, then Upload skill.
  4. Select the downloaded Clean Language zip file, then click Save.

Test it, or choose your spelling.

Organization

Whole organization: an owner can install Clean Language once for everyone. Click your name, then Organization settings, then Skills (in the Library and access section), then Add, then Upload skill, select the zip, and Save. It then appears for every member automatically, and members do not upload it individually.

Cannot upload the skill? Use a Claude Project instead

Use this if Skills never appear for you, or your organization has disabled Skills. It applies to one project rather than every chat. Use the instructions file from Get Clean Language.

  1. In Claude, click Projects, then New Project.
  2. Name it Clean Language.
  3. Under Project knowledge, click + and upload the saved file.
  4. Set the project instructions to: Use the Clean Language instructions in project knowledge for every response unless I explicitly tell you not to.
