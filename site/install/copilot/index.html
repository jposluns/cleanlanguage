Install

Copilot

Last verified 1 September 2026.

There are 2 ways to set up Clean Language in Copilot. Copilot Studio loads the full skill, the same zip file Claude and ChatGPT use, so it is the better choice where you have it. A Microsoft 365 Copilot agent cannot load a skill, so it takes the standard as pasted instructions instead.

Copilot Studio

Copilot Studio

This is the recommended Copilot method. It loads the complete skill, so the full standard is available to the agent rather than a shortened copy. Use the skill (zip) from Get Clean Language.

  1. On a computer, open copilotstudio.microsoft.com.
  2. Open your list of agents and click New agent.
  3. Click Skills, then upload the Clean Language zip file.
  4. Finish creating the agent as you normally would.
  5. Link the agent to any of your business processes, following the standard Copilot Studio steps.

Test it, or choose your spelling.

Whole company

Whole company: an administrator can create the agent once in Copilot Studio, then publish and deploy it to the organization through the standard Copilot Studio process, so everyone writes with Clean Language without building their own agent. Availability is a deliberate step and does not follow automatically from publishing.

Microsoft 365 Copilot agent

Microsoft 365 Copilot agent

Use this if you do not have Copilot Studio. A Microsoft 365 Copilot agent caps its instructions at 8000 characters, so paste the 8k file as the instructions and add the full standard as reference. Use the files from Get Clean Language.

  1. Open Microsoft 365 Copilot on a computer.
  2. Open the agents panel and click New agent. Copilot offers to build the agent for you or to let you set it up yourself; click Skip to customize it yourself.
  3. Name it Clean Language. For the description, you can use: Applies the Clean Language writing standard so responses are precise, direct, and natural.
  4. Open cleanlanguage-8k.md, copy all of it, and paste it into the Instructions box.
  5. Find the option to add specific websites, and add https://cleanlanguage.ai/downloads/cleanlanguage.md as reference the agent can consult; the pasted instructions are what it follows.
  6. Click Create, then select Clean Language whenever you write.

No agent access?

No agent access? Open cleanlanguage.md from Get Clean Language (double-click it; it opens in Notepad or TextEdit), select all the text, copy it, paste it into a Copilot chat, and say: Follow these writing rules for this conversation. Or open the instructions page and click Copy.
