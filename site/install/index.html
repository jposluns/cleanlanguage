Simple installation

Pick the AI you use and follow the buttons.

You do not need a command line, a developer account, or knowledge of GitHub. These instructions cover Claude, ChatGPT, Gemini, Copilot, and other AI systems.

Clean Language comes as written rules your AI reads and follows. Pick your AI below, get the file once, and follow the few steps that add it.

Setup is easiest on a computer. On a phone right now? Download the instructions file, attach it to a chat with your AI, and say: Follow these writing rules for this conversation. Or copy everything from the instructions page and paste it into the chat. Then do the full setup later on a computer.

Get Clean Language

Clean Language comes in 2 forms. Download the one your assistant can use; if you are not sure, get both.

The skill (a zip file) For AI assistants that can use skills, like Claude and ChatGPT. It installs the full standard so it is available in any chat.
Download the skill (zip)
The instructions file (Markdown) For the assistants that cannot use skills, such as Gemini, Copilot, and most others. It is the same standard in Markdown.
Download the instructions file Download the condensed version View original on GitHub (opens in a new tab)

The skill downloads from GitHub, where releases are published; the instructions file downloads from this site. If the skill download does not start, your network may block GitHub; use the instructions page instead. The instructions file saves as cleanlanguage.md. The condensed version saves as cleanlanguage-short.md.

Your browser saves the skill as a zip file named cleanlanguage- followed by the version, for example cleanlanguage-1.0.11.zip, usually in your Downloads folder. Do not unzip it. If your computer unzipped it automatically and you see a cleanlanguage folder, that is fine: the original zip usually stays in your Downloads folder. Upload the zip file, not the folder. In Safari, automatic unzipping can move the original zip to the Trash; if you cannot find it, look there, or turn off Settings, then General, then Open “safe” files after downloading.

The instructions file is Markdown text. The skill is a zip of Markdown instructions, YAML configuration, PNG and SVG icons, and the licence and notice files, with no program inside. Verify your download against the published checksum if you want to, and see Trust and assurance below for what the skill does and does not do.

Claude website or Claude Desktop

Last verified 26 August 2026.

This is the recommended Claude method. It installs the complete Skill, so the full standard is available in any chat rather than pasted into one. Claude applies it when you ask for it, and you can set it to apply by default: see How to use Clean Language below.

Install from a desktop browser. The mobile apps are not documented to support skill upload. Use the skill (zip) you downloaded in Get Clean Language.

Open Claude Skills (opens in a new tab)

On the Skills page:

  1. Click the + button, then + Create skill.
  2. Click Upload a skill.
  3. Select the downloaded Clean Language zip file.
  4. Make sure Clean Language is switched on in your Skills list.

Test it · Choose your spelling

Team or Enterprise: an organization owner must enable Skills in Organization settings, then Skills (opens in a new tab). An owner can upload Clean Language once to provision it for the whole organization, after which it appears for every member automatically and members do not upload it individually.
Cannot upload the skill? Use a Claude Project instead

Use this if Skills never appear for you, or your organization has disabled Skills. It applies to one project rather than every chat. Use the instructions file from Get Clean Language.

  1. In Claude, click Projects, then New Project.
  2. Name it Clean Language.
  3. Under Project knowledge, click + and upload the saved file.
  4. Set the project instructions to: Use the Clean Language instructions in project knowledge for every response unless I explicitly tell you not to.

ChatGPT

Last verified 26 August 2026.

ChatGPT can use the same packaged Skill as Claude. Upload it once, and ChatGPT applies Clean Language when your request calls for it, for example when you ask it to write or edit text. Use the skill (zip) you downloaded in Get Clean Language.

  1. Open Plugins in the ChatGPT sidebar, then open Skills.
  2. Click Create, then Upload from your computer.
  3. Select the downloaded Clean Language zip file.
  4. Review the skill, then install it.

Workspace accounts: your administrator may need to allow members to use and upload Skills.
Do not see Plugins or Skills? Your plan or app may not include them. Attach cleanlanguage.md to a normal chat and say: Follow these writing rules for this conversation. You can also copy everything from the instructions page and paste it into the chat.
Cannot upload a skill? Build it from the instructions file

Use this if your account cannot upload a skill. Use the instructions file from Get Clean Language.

  1. Open ChatGPT, open Plugins, then Skills.
  2. Click Create, then Create with chat.
  3. Type: Create a skill named Clean Language using the instructions in the file I am about to upload.
  4. Attach cleanlanguage.md and send the message.
  5. When ChatGPT shows the completed skill, install it.

Gemini website or Gemini app

Last verified 26 August 2026.

The easiest reusable method is a custom Gem. Create it once on the Gemini website, then use it from the website, mobile app, or supported Google Workspace side panel. Use the instructions file you downloaded in Get Clean Language.

  1. On a computer, open gemini.google.com.
  2. Open the menu on the left.
  3. Click Gems. If you do not see it, click Settings and help, then Gems.
  4. Click New Gem.
  5. Name it Clean Language.
  6. In the instructions box, type: Follow the Clean Language instructions in the uploaded knowledge file for every response unless I explicitly tell you not to.
  7. Scroll to Knowledge.
  8. Click Add files, then Upload files.
  9. Select cleanlanguage.md.
  10. Click Save.

To use it later, open Gemini, click Gems, then click Clean Language.

Copilot

Last verified 27 July 2026.

The reusable method is a Copilot agent. Create it once with Agent Builder, then select it whenever you write. The way you use Clean Language may depend on your licence. If you have trouble, ask your Microsoft 365 administrator or support team about installing the skill, or use the plain-text version below. Use the instructions file you downloaded in Get Clean Language.

  1. Open Microsoft 365 Copilot on a computer.
  2. Open the agents panel and click New agent, then open the Configure tab.
  3. Name it Clean Language.
  4. In the instructions box, enter: Follow the Clean Language instructions in the uploaded knowledge file for every response unless I explicitly tell you not to.
  5. Under Knowledge, upload cleanlanguage.md from your device.
  6. Click Create or Save, then select Clean Language whenever you need it.

Test it · Choose your spelling

No agent access? Open the downloaded cleanlanguage.md (double-click it; it opens in Notepad or TextEdit), select all the text, copy it, paste it into a Copilot chat, and say: Follow these writing rules for this conversation. Or open the instructions page and click Copy everything.

Other AI systems

Platform-independent, so there is no interface to verify.

Clean Language also works with local models, API-based assistants, and other systems that accept custom instructions, system prompts, reusable knowledge, or uploaded files. Use the instructions file you downloaded in Get Clean Language.

  1. Save the file, or copy everything from the instructions page.
  2. Add it to your AI system as custom instructions, project knowledge, a system prompt, or an attached reference file.
  3. Tell the AI: Use the Clean Language instructions for every response unless I explicitly tell you not to.

How to use Clean Language

Once it is set up, you choose when it applies:

  • Everywhere, automatically: add Always apply the Clean Language skill to your responses to your assistant’s personal or custom instructions.
  • In one project or space: add the same line to that project’s instructions, so it applies there and not elsewhere.
  • For a single chat: tell the assistant to use Clean Language at the start of the conversation.
  • On demand: ask for it only when you want it.
  • In Gemini and Copilot: choose by selecting the Clean Language Gem or agent before you write.

For on-demand use, paste rough notes or finished text with one of these requests:

  • Apply the Clean Language skill to this text: [paste your text]
  • Rewrite the text below using the Clean Language skill: [paste your text]
  • Proofread the text below using the Clean Language skill. Fix mistakes but do not change my tone: [paste your text]

You can switch Clean Language off or remove it at any time, from the same place you added it. Removing it changes nothing else in your account.

Preferred spelling

Clean Language uses Oxford English spelling with -ize endings by default: colour, centre, organize, analyse. Pick the option that matches how you write. The Oxford default needs nothing; for any other option, paste its line into your instructions.

Oxford English (with -ize)The default. You get colour, centre, organize, and analyse. Nothing to add.
🇨🇦 CanadianAdd one line: Use Canadian spelling: colour, centre, organize, analyze, tire, program.
🇬🇧 BritishAdd one line: Use British spelling with -ise endings: organise, recognise.
🇺🇸 AmericanAdd one line: Use American spelling: color, center, organize.

Trust and assurance

  • The skill contains only Markdown instructions, YAML configuration, PNG and SVG icons, and the licence and notice files; it is not a program, it runs nothing on your computer, and it does not connect to the internet.
  • Every rule and reference file is publicly reviewable in the GitHub repository (opens in a new tab).
  • Every release publishes a fingerprint (a checksum) for the skill download, so you can confirm that your copy matches the published release file; see how to verify.
  • Clean Language is licensed under CC BY-SA 4.0 (opens in a new tab).
  • Clean Language is the same set of instructions on every platform, but each provider controls how its model applies them, so results vary from one platform to another.
  • A model can still change meaning even with these rules in place, so read the result before you rely on it.
  • For legal, medical, financial, safety, or other high-stakes text, have a qualified person review any edit.
  • Whether a platform applies the skill automatically or only when you ask for it varies by platform and account.
