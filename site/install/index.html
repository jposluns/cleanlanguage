Simple installation

Pick the AI you use and follow the buttons.

You do not need a command line, a developer account, or knowledge of GitHub. These instructions cover Claude, ChatGPT, Gemini, Copilot, and other AI systems.

Clean Language comes as one small file, called a skill: written rules your AI reads and follows. You download the file, then upload it to your AI.

Setup is easiest on a computer. On a phone right now? Download the instructions file, attach it to a chat with your AI, and say: Follow these writing rules for this conversation. Or copy everything from the instructions page and paste it into the chat. Then do the full setup later on a computer.

Claude website or Claude Desktop

Last verified 26 August 2026.

This is the recommended Claude method. It installs the complete Skill, so the full standard is available in any chat rather than pasted into one. Claude applies it when you ask for it, and you can set it to apply by default: see How to use Clean Language below.

Install from a desktop browser. The mobile apps are not documented to support skill upload.

Step 1: download the skill

Download the Clean Language skill (zip)

The file downloads from GitHub, where releases are published. If the download does not start, your network may block GitHub; use the instructions page instead.

Your browser saves a zip file named cleanlanguage- followed by the version, for example cleanlanguage-1.0.11.zip, usually in your Downloads folder. Do not unzip it. If your computer unzipped it automatically and you see a cleanlanguage folder, that is fine: the original zip is still in your Downloads folder. Upload the zip file, not the folder. In Safari, automatic unzipping can move the original zip to the Trash; if you cannot find it, look there, or turn off Settings, then General, then Open "safe" files after downloading.

The file contains only written instructions for the AI. It is not a program, it runs nothing on your computer, and it does not connect to the internet.

Step 2: upload it to Claude

Open Claude Skills (opens in a new tab)

On the Skills page:

  1. Click the + button, then + Create skill.
  2. Click Upload a skill.
  3. Select the downloaded Clean Language zip file.
  4. Make sure Clean Language is switched on in your Skills list.

Test it in a new chat. First ask for some ordinary prose:

Write three short paragraphs about planning a team offsite.

Then run that same text through Clean Language:

Apply Clean Language to the text above.

Compare the two versions. If the second is clearly tighter and more direct, with filler and fake enthusiasm gone, it is working. If Claude says it does not know what Clean Language is, repeat the steps or use the fallback below.

You can switch Clean Language off or remove it at any time, from the same place you added it. Removing it changes nothing else in your account.

Team or Enterprise: an organization owner must enable Skills in Organization settings, then Skills (opens in a new tab). An owner can upload Clean Language once to provision it for the whole organization, after which it appears for every member automatically and members do not upload it individually.
Cannot upload the skill? Use a Claude Project instead

Use this if Skills never appear for you, or your organization has disabled Skills. It applies to one project rather than every chat.

  1. Download instructions View original on GitHub (opens in a new tab)
  2. In Claude, click Projects, then New Project.
  3. Name it Clean Language.
  4. Under Project knowledge, click + and upload the saved file.
  5. Set the project instructions to: Use the Clean Language instructions in project knowledge for every response unless I explicitly tell you not to.

Workspace accounts: your administrator may need to allow members to use and upload Skills.

Cannot upload a skill? Build it from the instructions file

Use this if your account cannot upload a skill.

  1. Download instructions View original on GitHub (opens in a new tab)
    The file saves as cleanlanguage-instructions.txt.
  2. Open ChatGPT, open Plugins, then Skills.
  3. Click Create, then Create with chat.
  4. Type: Create a skill named Clean Language using the instructions in the file I am about to upload.
  5. Attach cleanlanguage-instructions.txt and send the message.
  6. When ChatGPT shows the completed skill, install it.

Gemini website or Gemini app

Last verified 26 August 2026.

The easiest reusable method is a custom Gem. Create it once on the Gemini website, then use it from the website, mobile app, or supported Google Workspace side panel.

Step 1: download the instructions

Download instructions View original on GitHub (opens in a new tab)

The file saves as cleanlanguage-instructions.txt.

Step 2: create the Gem

  1. On a computer, open gemini.google.com.
  2. Open the menu on the left.
  3. Click Gems. If you do not see it, click Settings and help, then Gems.
  4. Click New Gem.
  5. Name it Clean Language.
  6. In the instructions box, type: Follow the Clean Language instructions in the uploaded knowledge file for every response unless I explicitly tell you not to.
  7. Scroll to Knowledge.
  8. Click Add files, then Upload files.
  9. Select cleanlanguage-instructions.txt.
  10. Click Save.

To use it later, open Gemini, click Gems, then click Clean Language.

Test it: open the Clean Language Gem, ask for ordinary prose such as Write three short paragraphs about planning a team offsite., then send Apply Clean Language to the text above. Compare the two versions. If the second is clearly tighter and more direct, with filler and fake enthusiasm gone, it is working. If Gemini says it does not know what Clean Language is, repeat the steps.

You can switch Clean Language off or remove it at any time, from the same place you added it. Removing it changes nothing else in your account.

Mobile note: create and edit the Gem on the Gemini website. After saving it, the Gem appears in the Gemini mobile app.

Copilot

Last verified 27 July 2026.

The reusable method is a Copilot agent. Create it once with Agent Builder, then select it whenever you write. The way you use Clean Language may depend on your licence. If you have trouble, ask your Microsoft 365 administrator or support team about installing the skill, or use the plain-text version below.

Step 1: download the instructions

Download instructions View original on GitHub (opens in a new tab)

The file saves as cleanlanguage-instructions.txt.

Step 2: create the agent

  1. Open Microsoft 365 Copilot on a computer.
  2. Open the agents panel and click New agent, then open the Configure tab.
  3. Name it Clean Language.
  4. In the instructions box, enter: Follow the Clean Language instructions in the uploaded knowledge file for every response unless I explicitly tell you not to.
  5. Under Knowledge, upload cleanlanguage-instructions.txt from your device.
  6. Click Create or Save, then select Clean Language whenever you need it.

Test it: select Clean Language, ask for ordinary prose such as Write three short paragraphs about planning a team offsite., then send Apply Clean Language to the text above. Compare the two versions. If the second is clearly tighter and more direct, with filler and fake enthusiasm gone, it is working. If Copilot says it does not know what Clean Language is, repeat the steps or use the fallback below.

You can switch Clean Language off or remove it at any time, from the same place you added it. Removing it changes nothing else in your account.

No agent access? Open the downloaded cleanlanguage-instructions.txt (double-click it; it opens in Notepad or TextEdit), select all the text, copy it, paste it into a Copilot chat, and say: Follow these writing rules for this conversation. Or open the instructions page and click Copy everything.

How to use Clean Language

Once it is set up, you choose when it applies:

  • Everywhere, automatically: add Always apply Clean Language to your responses to your assistant's personal or custom instructions.
  • In one project or space: add the same line to that project's instructions, so it applies there and not elsewhere.
  • For a single chat: tell the assistant to use Clean Language at the start of the conversation.
  • On demand: ask for it only when you want it.
  • In Gemini and Copilot: choose by selecting the Clean Language Gem or agent before you write.

For on-demand use, paste rough notes or finished text with one of these requests:

  • Apply Clean Language to this draft: [paste your text]
  • Rewrite this using Clean Language: [paste your text]
  • Proofread this using Clean Language. Fix mistakes but do not change my tone: [paste your text]

Preferred spelling

Clean Language uses British and Canadian spelling by default. Pick the option that matches how you write.

🇨🇦 CanadianThe default. You get colour, centre, and organize. Nothing to add.
🇬🇧 BritishAlso the default. You get colour, centre, and organize. Nothing to add.
🇺🇸 AmericanAdd one line to your instructions: Use American spelling: color, center, organize.

Trust and assurance

  • The skill contains only text instructions, configuration, and icons; it is not a program, it runs nothing on your computer, and it does not connect to the internet.
  • Every rule and reference file is publicly reviewable in the GitHub repository (opens in a new tab).
  • Every release publishes a fingerprint (a checksum) for the skill download, so you can confirm that your copy matches the original; see how to verify.
  • Clean Language is licensed under CC BY-SA 4.0 (opens in a new tab).
  • Clean Language is the same set of instructions on every platform, but each provider controls how its model applies them, so results vary from one platform to another.
  • A model can still change meaning even with these rules in place, so read the result before you rely on it.
  • For legal, medical, financial, safety, or other high-stakes text, have a qualified person review any edit.
  • Whether a platform applies the skill automatically or only when you ask for it varies by platform and account.
