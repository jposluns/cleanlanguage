Pick the AI you use and follow the steps

You do not need a command line, a developer account, or knowledge of GitHub. Clean Language comes as written rules your AI reads and follows: pick your AI, get the file once, and follow the few steps on its page.

Scope

The condensed and compact files carry less of the finer detail than the full file. Skill upload is documented for desktop browsers; the mobile apps are not documented to support it.

On a phone

Setup is easiest on a computer. On a phone right now? Download the instructions file, attach it to a chat with your AI, and say: Follow these writing rules for this conversation. Or copy everything from the instructions page and paste it into the chat. Then do the full setup later on a computer.

Get Clean Language

Get Clean Language

Clean Language comes in 2 forms. Download the one your assistant can use; if you are not sure, get both.

The skill

cleanlanguage-1.0.14.zip (opens in a new tab)

zip, version 1.0.14

For AI assistants that can use skills, like Claude, ChatGPT, and Copilot Studio. It installs the full standard so it is available in any chat.

The instructions file

cleanlanguage.md

Markdown, full, 29 KB

For the assistants that cannot use skills, such as Gemini, a Microsoft 365 Copilot agent, and most others. It is the same standard in Markdown, in 3 sizes; also condensed, 11k and compact, 8k. Pick the largest your assistant accepts: the smaller files carry less of the finer detail to fit a tighter instruction limit, so they are a little less capable. View the original on GitHub (opens in a new tab).

The skill downloads from GitHub, where releases are published; the instructions file downloads from this site. If the skill download does not start, your network may block GitHub; use the instructions page instead. The full instructions file saves as cleanlanguage.md; the smaller versions save as cleanlanguage-11k.md and cleanlanguage-8k.md.

Your browser saves the skill as a zip file named cleanlanguage- followed by the version, for example cleanlanguage-1.0.14.zip, usually in your Downloads folder. Do not unzip it. If your computer unzipped it automatically and you see a folder with the same name, that is fine: the original zip usually stays in your Downloads folder. Upload the zip file, not the folder.

In Safari, automatic unzipping can move the original zip to the Trash; if you cannot find it, look there, or turn off Settings, then General, then Open “safe” files after downloading.

The instructions file is Markdown text. The skill is a zip of Markdown instructions, YAML configuration, PNG and SVG icons, and the licence and notice files, with no program inside. Verify your download against the published checksum if you want to, and see Trust and assurance below for what the skill does and does not do.

Test it

Test it

Once it is set up, paste this specimen and ask your AI to apply Clean Language to it:

In today’s fast-paced landscape, we are laser-focused on leveraging synergies to deliver truly best-in-class outcomes; the launch is scheduled for 14 October.

Compare the result with the original. If the filler and buzzwords are gone and it keeps “14 October”, it is working. If your AI says it does not know what Clean Language is, repeat the setup steps on your AI’s page, or use the fallback on that page if one is offered.

How to use

How to use Clean Language

Once it is set up, you choose when it applies:

  • Everywhere, automatically: add Always apply the Clean Language skill to your responses to your assistant’s personal or custom instructions.
  • In one project or space: add the same line to that project’s instructions, so it applies there and not elsewhere.
  • For a single chat: tell the assistant to use Clean Language at the start of the conversation.
  • On demand: ask for it only when you want it.
  • In Gemini and Copilot: choose by selecting the Clean Language Gem or agent before you write.

For on-demand use, paste rough notes or finished text with one of these requests:

  • Apply the Clean Language skill to this text: [paste your text]
  • Rewrite the text below using the Clean Language skill: [paste your text]
  • Proofread the text below using the Clean Language skill. Fix mistakes but do not change my tone: [paste your text]

You can switch Clean Language off or remove it at any time, from the same place you added it. Removing it changes nothing else in your account.

Spelling

Preferred spelling

Clean Language uses Oxford English spelling with -ize endings by default: colour, centre, organize, analyse. Pick the option that matches how you write. The Oxford default needs nothing; for any other option, paste its line into your instructions.

  • Oxford English (with -ize): the default. You get colour, centre, organize, and analyse. Nothing to add.
  • Canadian: add one line: Use Canadian spelling: colour, centre, organize, analyze, tire, program.
  • British: add one line: Use British spelling with -ise endings: organise, recognise.
  • American: add one line: Use American spelling: color, center, organize.

Assurance

Trust and assurance

  • The skill contains only Markdown instructions, YAML configuration, PNG and SVG icons, and the licence and notice files; it is not a program, it runs nothing on your computer, and it does not connect to the internet.
  • Every rule and reference file is publicly reviewable in the GitHub repository (opens in a new tab).
  • Every release publishes a fingerprint (a checksum) for the skill download, so you can confirm that your copy matches the published release file; see how to verify.
  • Clean Language is licensed under CC BY-SA 4.0 (opens in a new tab).
  • Clean Language is the same set of instructions on every platform, but each provider controls how its model applies them, so results vary from one platform to another.
  • A model can still change meaning even with these rules in place, so read the result before you rely on it.
  • For legal, medical, financial, safety, or other high-stakes text, have a qualified person review any edit.
  • Whether a platform applies the skill automatically or only when you ask for it varies by platform and account.
