Install

ChatGPT

Last verified 27 August 2026.

ChatGPT can use the same packaged Skill as Claude. Upload it once, and ChatGPT applies Clean Language when your request calls for it, for example when you ask it to write or edit text. Use the skill (zip) from Get Clean Language.

  1. Click Plugins in the left menu bar, then Skills at the top, beside Plugins.
  2. Click the plus, then Upload from your computer.
  3. Select the downloaded Clean Language zip file.
  4. When the green check mark appears, click the X to close the window.

Test it, or choose your spelling.

Team workspace

Team workspace, as an administrator: click your team name, then Workspace settings, then Skills, then the plus, select the zip, and click the X when the green check mark appears. To let members use it, click the skill’s name, then the ... menu, and change who has access.

No Skills?

Do not see Plugins or Skills? Your plan or app may not include them. Attach cleanlanguage.md from Get Clean Language to a normal chat and say: Follow these writing rules for this conversation. You can also copy everything from the instructions page and paste it into the chat.

Cannot upload a skill? Build it from the instructions file

Use this if your account cannot upload a skill. Use the instructions file from Get Clean Language.

  1. Open ChatGPT, open Plugins, then Skills.
  2. Click the plus, then Create with chat.
  3. Type: Create a skill named Clean Language using the instructions in the file I am about to upload.
  4. Attach cleanlanguage.md and send the message.
  5. When ChatGPT shows the completed skill, install it.
